# Engineer Karl — Privileged Intent Review

Engineer Karl supports The Gaming Council's Discord community through memberflow reporting, staff coordination, recruitment tracking, member support, moderation, and game integrations.

This application requests **Guild Members** and **Message Content** access for the functions described below.

## Application documents

- [Application overview](request.md)
- [Workflow use cases and intent requirements](use-cases.md)

## Recruitment, ROs, and memberflow

Staff recruit people into TGC's in-game guilds, then use ROs (reach-outs) to bring existing guild members into Discord and build community relationships. Karl's activity leaderboards and memberflow reports help leadership direct that work and assess the results.

[View the recruitment, RO, and memberflow workflow](use-cases.md#recruitment-ros-and-memberflow).
